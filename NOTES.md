# Cosmoq — разбор дизайн-системы (референс для Mexum)

Локальная копия https://cosmoq.framer.website/ — Framer-сайт (SPA, стили инжектятся
рантаймом, отдельного .css файла нет). Поэтому вместо "чистого" исходника здесь:

- `index.html` — сырой HTML-шелл, который отдаёт сервер (до JS-рендера, 366 строк)
- `rendered.html` — полный DOM **после** рендера React/Framer-рантайма (то, что
  реально видит пользователь: все классы, инлайн-стили, текст) — 845KB
- `assets/` — 76 картинок/svg/webp/mp4, реально используемых на странице
- `js/` — 28 .mjs чанков (React + Framer Motion + рантайм, сильно минифицированы —
  не readable, оставлены для полноты копии, не для чтения)

## Извлечённые дизайн-токены

**Шрифты**: `Inter` (текст) и `Inter Display` (заголовки, вес 500) — это открытые
шрифты (SIL OFL), Framer просто раздаёт их со своего CDN с unicode-range
сабсеттингом. Для Mexum можно взять напрямую с Google Fonts, копировать файлы
не нужно.

**Заголовок hero**: `Inter Display`, weight 500, ~82px.

**Glass-рецепт** (карточки/пилюли поверх тёмного фона):
```css
backdrop-filter: blur(8px–10px);
background: rgba(255, 255, 255, 0.07);
border-radius: 999px; /* пилюли */ или больше для карточек
box-shadow: inset -3px -2px 8px 0px rgba(255, 255, 255, 0.07); /* тонкая подсветка сверху-слева */
```

**Фон**: чёрный (`#000`), тёмная "туманность"/дуга градиента (оранжево-розовый →
синий) за hero-заголовком, звёздный шум поверх.

## Архитектурный паттерн секций (повторяется по всему сайту)
Маленький капс-лейбл (эйбрау) → крупный заголовок → короткий саппорт-текст:
```
EXCEPTIONALITIES → "What sets COSMOQ apart" → подпись
FEATURES → "All-in-one AI for enterprise" → подпись
STEPS TO USE → "3 Steps to Kickstart" → подпись
PRICING → "Flexible Plans for Every" → подпись
FAQ → "Curious About Cosmoq?" → подпись
```
Порядок секций: Hero → intro-строка → карточки-преимущества → CTA-баннер →
табы-фичи → табы-продукты по индустриям → 3 шага → security → отзывы →
тарифы (переключатель monthly/yearly) → FAQ-аккордеон → интеграции → финальный CTA.

## Что берём для Mexum
- Шрифтовую пару (Inter / Inter Display) и типографику заголовков
- Glass-рецепт для карточек/пилюль/бейджей
- Паттерн "эйбрау + заголовок + подпись" на секциях
- НЕ берём: тёмную AI-тематику целиком (звёзды/туманность), это опционально —
  зависит от финального решения по светлому/тёмному направлению
